전남대학교 졸업 플래너

전공·계열·입학연도를 선택하면 브라우저에서 바로 맞춤형 엑셀(.xlsx) 파일을 생성합니다.
매크로 없이 셀 수식만으로 동작하여 Google Sheets · LibreOffice · Excel 어디서나 열 수 있습니다.

플래너 생성

학생 정보

계열은 임의 선택이 아니라 소속 학과/학부가 속한 대학 구분에 따릅니다 (교학규정 별표1). 학과 사무실·학사요람에서 확인하세요.

전공 선택
복수전공 / 부전공 / 연계전공 (선택, 여러 개 가능)

주전공은 1개만 선택합니다. 복수·부·연계전공은 개수 제한 없이 추가할 수 있습니다. 졸업 최소 평점과 교양최대인정학점은 주전공 학과 기준으로 자동 결정됩니다.

주요 기능

  • 전공별 전용 시트 + 이수구분별·총 이수학점·GPA 자동 집계
  • 코드 입력 시 교과목명·학점·이수구분 자동완성 (주전공 우선)
  • 복수·부·연계전공 이수학점 요건과 졸업 가능 여부 자동 판정
  • 매크로/스크립트 없음 — 어떤 표 계산 앱에서도 안전하게 사용

사용 방법

  1. 위에서 학생 정보와 전공을 선택하고 생성 버튼을 누릅니다.
  2. 내려받은 .xlsx를 Google Sheets/Excel/LibreOffice로 엽니다.
  3. 대시보드의 "이수 과목 입력" 표에만 과목을 입력하면 나머지는 자동 계산됩니다.

졸업요건은 학과 · 입학연도에 따라 다를 수 있으니 반드시 공식 규정을 확인하세요.
